---

## 📚 Key Learnings

### 🟥 Offensive Security (Red Team)

- Focuses on **simulating attacks** to test system security.
- Roles include:
  - Penetration Tester
  - Ethical Hacker
  - Red Teamer
- Uses tools like `Nmap`, `Metasploit`, and custom scripts to find vulnerabilities.

### 🟦 Defensive Security (Blue Team)

- Focuses on **monitoring, detecting, and responding** to threats.
- Roles include:
  - SOC Analyst
  - Threat Hunter
  - Incident Responder
- Relies on logs, SIEMs, firewalls, and behavior analysis.

### 🧠 Takeaways

- Offensive and Defensive security roles are two sides of the same coin.
- Organizations require **both perspectives** to maintain strong security.
- This foundational knowledge is critical before diving into hands-on labs.
